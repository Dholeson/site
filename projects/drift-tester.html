How this is measured

Measure rest samples each stick for 2 seconds. Rest offset is the distance from centre to the stick's average resting position, on the browser's scale where the edge of the stick's travel is 1. Jitter is how far the readings spread around that position (root mean square). The dashed ring is drawn at 0.08, a common size for a game's deadzone. Games set their own deadzones, so this page reports numbers without a grade. The dot shows the stick's current position; the fading trail is only a guide.

How it works

The browser reports each stick as a pair of axes, each running from −1 to 1. This page reads them once per animation frame, plots the position and keeps a short trail, so a glitch that lasts a single frame stays on screen for a moment. Measure rest collects those readings for 2 seconds while the sticks are untouched, then works out the offset and jitter described above.

Nothing is uploaded. It all runs in your browser.
